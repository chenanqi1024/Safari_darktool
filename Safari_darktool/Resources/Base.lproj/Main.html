Setup

Enable it in Safari

  1. 1

    Open Safari Settings

    Use the button below to jump directly to the extension settings page.

  2. 2

    Turn on Safari Dark Tool

    In Extensions, check Safari Dark Tool and allow it on the websites you want to darken.

  3. 3

    Use the toolbar button

    Choose Dark, Original, or Auto, disable the current site, and tune brightness or contrast.

Modes

Dark forces local dark mode, Original restores the page, and Auto follows macOS appearance.

Site switch

Disable or restore dark mode for the website you are currently viewing.

Visual tuning

Adjust brightness, contrast, and sepia without uploading webpage contents.

Settings stay in Safari extension storage. Webpage contents are not uploaded.
